# 월별 근태 JSON 만들기

**사용자는 달과 연차·반차만 말한다. 나머지(공휴일 포함)는 이 스킬이 판정한다.**
형식·값을 짐작해 채우지 않고, 사용자가 말하지 않은 연차·반차를 지어내지 않고, 낡은 값은 덧붙이지 않고 갈아 끼운다.

## 0. 쓰는 때와 멈추는 때

쓴다: 「N월 근태」「근로내역」「출퇴근 json」「근태 만들어줘」, 근태 json을 주며 채워 달라고 할 때, 연차·반차 날짜를 알려줄 때.

안 쓴다:
- 실제 근무 기록을 **그대로 옮겨 달라**고 할 때 — 생성하지 말고 받은 값을 넣는다.
- 근태 프로그램 사용법·설치, 급여·정산 계산 — 이 스킬은 출퇴근 시각만 만든다.

| 상황 | 어떻게 |
|---|---|
| 원본 구조가 §1과 다르다(바깥 키·`Name`·`WorkTime` 위치가 다름) 또는 base64가 아닌 평문이다 | 만들지 말고 채워진 실물 샘플을 요청한다 |
| 사번·이름이 원본에 없다 | 지어내지 않고 묻는다 |
| 그 해 공휴일을 확정 못 하겠다 | 찍지 않는다. 확인하거나 묻는다 |
| 연차·반차를 안 알려줬다 | 없는 것으로 만든다. 출력의 「없음」을 보고에 붙인다 |
| 제출 프로그램 화면을 근거로 대야 한다 | 화면을 말로 그려내지 않고 사진을 요청한다 |

## 1. 형식 — 이것이 실물이다

출퇴근 기록 관리 프로그램(`WorkingTimeManageMent.dll`)이 읽는 형식이다. DLL의 `StartWorkTime`·`EndWorkTime` 프로퍼티와 실제 제출본 샘플로 확정했다.

```json
{"<사번>":{"Name":"<이름>","WorkTime":{
  "2026-06-01":{"StartWorkTime":"2026-06-01 09:35","EndWorkTime":"2026-06-01 17:56"},
  "2026-06-08":{"StartWorkTime":"2026-06-08 09:58","EndWorkTime":""}
}}}
```

| 자리 | 형식 |
|---|---|
| 바깥 키 | 사번. **원본에서 물려받는다** |
| `Name` | 이름. **원본에서 물려받는다** |
| 날짜 키 | `"YYYY-MM-DD"` 전체 날짜. 일자 두 자리(`"03"`)가 아니다 |
| `StartWorkTime` | `"YYYY-MM-DD HH:MM"` — 시각만 적지 않고 **날짜를 같이** 적는다 |
| `EndWorkTime` | 같은 형식. 퇴근을 안 찍은 날은 실물에서 빈 문자열 `""` |

파일 전체가 base64 한 줄이다(확장자는 `.json`). 원본이 `"WorkTime":{}`로 비어 있어도 위 형식이 맞다.
틀린 형식을 제출 폴더에 두면 그대로 나가 통째로 못 쓰게 된다.

## 2. 채우는 규칙

| 무엇 | 값 |
|---|---|
| 출근 | 09:30 고정 |
| 퇴근 | 18:00~18:30 사이 랜덤(분 단위) |
| 주말·공휴일·대체공휴일·연차 | 항목을 만들지 않는다 |
| 오전 반차 | 13:30 출근 ~ 랜덤 퇴근 |
| 오후 반차 | 09:30 출근 ~ 13:30 퇴근 |

## 3. 공휴일 판정 — 그 해 기준으로 확인한다

기억으로 적지 않는다. 해마다 요일이 바뀌고 음력 명절·선거일·임시공휴일은 날짜가 바뀐다.

- 고정: 신정 1/1 · 삼일절 3/1 · 어린이날 5/5 · 현충일 6/6 · 광복절 8/15 · 개천절 10/3 · 한글날 10/9 · 성탄절 12/25
- 음력·변동: 설 연휴 · 부처님오신날 · 추석 연휴 — 그 해 양력 날짜를 확인한다
- 선거일·임시공휴일: 그 해에 지정된 것이 있는지 확인한다

| 대체공휴일 | 언제 |
|---|---|
| 삼일절·광복절·개천절·한글날·부처님오신날·성탄절 | 토·일과 겹치면 |
| 어린이날 | 토·일 또는 다른 공휴일과 겹치면 |
| 설 연휴·추석 연휴 | 일요일 또는 다른 공휴일과 겹치면(토요일은 아니다) |
| 신정·현충일 | 없음 |

대체일은 그다음 첫 비공휴일 평일이다. 규정은 바뀔 수 있으니 확신이 없으면 그 해 「관공서의 공휴일에 관한 규정」을 확인하고, 못 하면 묻는다.

**주말과 겹친 공휴일도 `--공휴일`에 넣는다.** 그래야 비고가 「주말 · 개천절」로 찍혀 §5 공휴일 대조가 이름을 찾는다.
빼면 「주말」로만 찍혀 대조가 영원히 실패한다.

## 4. 돌린다 — 그 달 값은 인자로만

`근태만들기.py`는 이 스킬 폴더에 있다. 열어서 고치지 않는다.

```bash
PYTHONUTF8=1 python ~/.claude/skills/worktime-json/근태만들기.py \
    <원본json> <출력json> <연> <월> --공휴일 "<일:이름,...>" \
    [--연차 7,14] [--오전반차 21] [--오후반차 5]
```

| 인자 | 무엇 |
|---|---|
| `--공휴일` (필수) | §3으로 확정한 그 달 공휴일·대체공휴일. `"일:이름"`을 쉼표로. 이름 안 공백은 그대로 둔다. 정말 없는 달은 `--공휴일 없음` |
| `--연차`·`--오전반차`·`--오후반차` | 사용자가 **이번에 말한 날만**, 일자를 쉼표로(`7,14`). 안 말했으면 빼고, 출력이 「없음」을 찍는다 |

예 — 2026년 10월(3일 개천절이 토요일 → 5일 대체), 연차 14일, 오전반차 21일:

```bash
PYTHONUTF8=1 python ~/.claude/skills/worktime-json/근태만들기.py \
    10월.json 10월.json 2026 10 --공휴일 "3:개천절,5:개천절 대체공휴일,9:한글날" --연차 14 --오전반차 21
```

- 스크립트 흐름: 원본 base64 디코드 → 사번·이름 물려받기 → 근무일 판정 → 시각 생성 → 인코딩·저장 → **디코드 왕복 검증**.
- `--공휴일`이 없거나, 인자 개수·연월·숫자 형식이 틀리거나, 원본이 없으면 만들지 않고 사용법·받은 값을 내고 종료 코드 2로 멈춘다.
- `WorkTime`은 통째로 교체된다. 퇴근 랜덤은 `(연, 월)` 시드라 같은 달·같은 인자면 같은 결과가 나온다.
- 사용자가 날짜를 바꿔 말하면 이전 날짜를 빼고 새 날짜로만 다시 돌린다.
- **보고의 표·base64·검증 결과는 이 실행의 출력 그대로다.** 손으로 다시 적지 않는다.

## 5. 누락을 대조한다

돌리기 전에 사용자가 말한 것(대상 연월, 원본 경로, 연차·오전반차·오후반차 날짜 전부)과 §3에서 확정한 공휴일을 목록으로 적는다.
돌린 뒤 출력과 한 줄씩 대조해 지운다. 하나라도 남으면 멈추고 다시 넣는다.

| 검사 | 통과 조건 |
|---|---|
| 날짜 합산 | 근무일 + 주말 + 평일 공휴일 + 연차 = 그 달 일수(주말과 겹친 공휴일은 주말로만, 반차는 근무일로 센다) |
| 항목 수 | 출력의 「기록된 근무일」 = 그 달 평일 수 − 평일 공휴일 − 연차(달력으로 따로 센 값) |
| 연차 대조 | 목록의 연차 날짜가 전부 비고 `연차` |
| 반차 대조 | 목록의 반차 날짜가 전부 비고 `오전반차`·`오후반차`이고 13:30 경계 |
| 공휴일 대조 | 확정한 공휴일이 전부 비고에 이름으로 |
| 연월 대조 | 모든 날짜 키가 대상 연·월 |

## 6. 파일과 보고

- 원본을 스크래치패드에 먼저 백업하고, **원본이 있던 자리에 같은 이름으로** 낸다. 새 이름을 짓지 않는다.
- 이번 작업에서 참고용으로 다른 폴더에 만든 사본은 작업 뒤 지운다.
- 끝났다고 하려면: 왕복 검증 `True`, §5 여섯 검사 통과, 원본 자리 교체와 백업 확인.
- 보고: 날짜별 표(일·요일·출퇴근·비고), 근무일 수, 공휴일 판정(무엇이 며칠, 대체공휴일 여부), §5 여섯 줄 결과, 왕복 검증, base64 전문과 디코드된 첫 항목.

## 7. 스크립트를 고칠 때

사용자는 이 스크립트를 정답이자 템플릿으로 믿고 다음 달에 다시 쓴다.

- 달마다 바뀌는 값(공휴일·연차·반차)은 인자로만 받는다. 파일에 박으면 다음 달에 지난달 공휴일·남의 연차가 조용히 다시 들어간다
  (실제로 8/7 연차·8/21 오전반차가 박혀 있어 말하지 않아도 들어간 적이 있다).
- 고정 규칙 값(출근 09:30·반차 경계 13:30)은 상단 상수에, 퇴근 범위는 `퇴근()` 한 곳에만 둔다. 한 규칙은 한 자리에서만 판정한다.
- 입력이 잘못되면 트레이스백 대신 사용법과 받은 값을 내고 종료 코드 2. `--공휴일`이 없으면 만들지 않는다.
- 결과는 왕복 디코드로 검증한 뒤에만 통과다. 쓰지 않는 함수·인자·주석은 남기지 않는다.
