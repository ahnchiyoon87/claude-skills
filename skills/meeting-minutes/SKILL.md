# 회의록 — 전사본 → 시간대별 주제 요약

## 입력

- **전사 텍스트**: `Participants 3 02:14` 처럼 발화자와 시작 시각이 줄 머리에 붙은 클로바노트 내보내기, 또는 같은 모양의 텍스트. 이것이 기본 입력이다.
- **음성 파일만 있으면** Claude가 직접 들을 수 없으므로 먼저 STT로 시각이 붙은 텍스트를 만들어 달라고 알린다(faster-whisper · ElevenLabs Scribe 등, 사용자가 고른 것). 전사본 없이 요약을 지어내지 않는다.
- 같은 폴더나 프로젝트에 `용어집.md`(제품명 · 고객사 · 사람 이름 · 전문 용어)가 있으면 읽고, 이 스킬의 [references/용어집.md](references/용어집.md)와 합쳐 쓴다.

## 출력 형식 (고정)

맨 위 날짜 · 오전/오후 · 링크 줄은 사용자가 직접 쓰므로 **만들지 않는다.** 내용만 쓴다. 구간마다 다음 모양이다.

```
MM:SS~MM:SS

**주제 제목**

* 핵심 내용 한 줄
* 핵심 내용 한 줄
```

구간 사이는 빈 줄 하나다. 제목은 굵은 글씨, 불릿은 `*` 목록이다(붙여 넣을 곳이 Google Docs이고 거기서 ● 불릿으로 보인다).

- 구간은 **주제가 바뀌는 곳**에서 끊는다. 발화자가 바뀐다고 끊지 않고, 한 사람이 여러 주제를 말하면 주제마다 끊는다.
- 시각은 전사본에 있는 값만 쓴다. 구간 시작은 그 주제의 첫 발화 시각, 끝은 다음 구간 시작 직전 발화의 끝(없으면 그 구간 마지막 발화 시각)이다. 시각을 추측해 만들지 않는다.
- 주제 제목은 제목만 봐도 무슨 일인지 알게 쓴다(「클라우드 비용」「포스코 납품용 릴리즈」).
- 불릿은 **결정 · 진행 상태 · 이슈 · 다음 할 일**만 남기고, 인사 · 맞장구 · 말 더듬기는 뺀다. 숫자 · 날짜 · 고객사 · 사람 이름은 원문 그대로 지킨다.
- 발화자가 구분되고 담당이 중요하면 불릿 끝에 `(Participants 3)` 처럼 쓴다. 사용자가 이름을 알려 주면 이름으로 바꾼다.
- 한국어 구어체를 문어체 개조식으로 바꾼다. 원문에 없는 내용을 더하지 않는다.

## 전사 오류 교정

클로바노트 같은 STT는 제품명과 영어 용어를 비슷한 소리의 한국어로 받아 적는다(예: 온톨로지 → 온트로지컬 · 온트로지, 골든 쿼리 → 골드 커맨드, 로브 아키텍트 → 제품명 오인식).

1. 용어집에 있는 표기로 바로 고친다.
2. 용어집에 없지만 문맥상 확실한 것은 고치고, 요약 끝에 **「교정한 표기」** 목록으로 `원문 → 고친 말`을 보인다.
3. 확실하지 않은 것은 원문 그대로 두고 `(?)`를 붙인 뒤 같은 목록 아래 **「확인 필요」**에 모은다. 자신 있게 지어내지 않는다.

## 답하는 모양 (복붙용)

사용자는 전사본을 채팅에 붙이고 결과를 그대로 복사해 쓴다. 그래서 답은 이렇게 한다.

1. **코드 블록에 넣지 않고 마크다운 그대로 쓴다.** 채팅에 렌더된 글을 복사해 Google Docs에 붙이면 굵은 제목과 불릿이 살아 있어야 하기 때문이다. 코드 블록은 서식이 죽는다. 회의록 부분에는 위 「출력 형식」의 줄과 구간만 있고 설명 · 인사 · 표가 없다.
2. 회의록 뒤에 구분선(`---`)을 긋고 한두 줄만 덧붙인다: 교정한 표기, 확인 필요(있을 때만). 없으면 구분선도 쓰지 않는다. 사용자가 복사할 때 구분선 위까지만 고르면 된다.
3. 다음 할 일 표는 사용자가 달라고 할 때만 만든다. 기본 출력에 넣지 않는다.
4. 되묻지 않고 바로 요약한다. 전사본이 아니거나 시각이 없을 때만 한 줄로 알린다.

## 저장

- 채팅에 결과를 보이고, 저장할 곳을 묻지 않고 끝낸다. 파일로 달라고 하면 `YYYY-MM-DD_회의록.md`로 쓴다.
- Notion에 올리라고 했을 때만 Notion 커넥터로 페이지를 만든다. 회의 내용은 외부 전송이므로 사용자가 요청하지 않으면 올리지 않는다.
- 전사 원문 · 회의 내용은 비밀로 다룬다. 커밋하거나 스킬 폴더에 남기지 않는다.

## 확인

- 모든 구간의 시각이 전사본에 실제로 있는지, 구간끼리 겹치거나 빈 곳이 없는지 본다.
- 불릿의 숫자와 이름을 전사 원문과 대조한다.
